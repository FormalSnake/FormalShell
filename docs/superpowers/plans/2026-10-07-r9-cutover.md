# R9: cutover

Goal: the Rust shell is FormalShell. One package, one greeter, no
Quickshell, no QML, both Linux hosts running it.

Gate (checked 2026-10-07): `2026-10-07-r9-final-sweep.md` shows every leg
passing under `FS_IMPL=rust`, the QML table unchanged from before the
rewrite, and the parity backlog empty or each remaining line accepted by the
owner.

## Task 1: packaging

- `.#formalshell` builds the Rust binary (today `.#formalshell-rs`); the
  old QML package and `.#formalshell-rs` go. `formalshell-ipc` is the IPC
  entry point everywhere (Hyprland Lua binds, docs, the home-manager
  module).
- `nixos-module.nix` and the home-manager module start the Rust binary;
  `services.formalshell-greeter.implementation` goes, the Rust greeter is
  the greeter.
- Arch PKGBUILD and Debian packaging build the Rust workspace (vendored
  crates, offline) with the same runtime dependency lists;
  `dev/native-check.sh` passes for trixie, forky, resolute and arch.

## Task 2: delete the QML shell

- `shell/`, `greeter/`'s QML, `tests/*.qml` and their stubs and fixtures
  that only QML read, the quickshell flake input, the `qml-tests` and
  `qmllint` checks, `*.frag` shaders, `FS_IMPL` (Rust is the only
  implementation; `dev/smoke.sh` loses its QML path), `dev/parity.sh` and
  `dev/ipc-golden.sh`'s recording against `qs` (the golden file stays as a
  fixed contract).
- Pure logic crates keep their ported tests; fixtures they read move under
  `crates/`.

## Task 3: docs

- CLAUDE.md rewritten for the Rust tree (verification loop, rig, hard
  rules: the pure QML/JS rule is gone; the ScreencopyView ban becomes the
  capture rule), README, docs/USAGE.md, docs/ARCHITECTURE.md, DESIGN.md
  references to QML components.

## Task 4: measure on e1504g (owner present)

- The R0 table again with the real shell, nested on e1504g in power
  saver: idle CPU, spinner CPU, panel and launcher frame times, the 33 ms
  bar gap during a launcher open, RSS after an hour, cold start. Against
  the spec's budgets.

## Task 5: ship (owner's go required)

- Push, bump `formalshell` in `~/.config/nix`, rebuild g815 on itself and
  e1504g from g815 (`nixos-rebuild switch --flake .#e1504g --target-host
  e1504g --sudo`), confirm each host's `formalshell.service` runs the Rust
  binary.

# R9: cutover

Goal: the Rust shell is FormalShell. One package, one greeter, no
Quickshell, no QML, both Linux hosts running it.

Gate (checked 2026-10-07): `2026-10-07-r9-final-sweep.md` shows every leg
passing under `FS_IMPL=rust`, the QML table unchanged from before the
rewrite, and the parity backlog empty or each remaining line accepted by the
owner.

## Task 1: packaging

- `.#formalshell` builds the Rust binary (today `.#formalshell-rs`); the
  old QML package and `.#formalshell-rs` go. `formalshell-ipc` is the IPC
  entry point everywhere (Hyprland Lua binds, docs, the home-manager
  module).
- `nixos-module.nix` and the home-manager module start the Rust binary;
  `services.formalshell-greeter.implementation` goes, the Rust greeter is
  the greeter.
- No native distro packages (owner, 2026-10-07): `packaging/`,
  `dev/native-check.sh`, `dev/smoke.d/native.sh` and the release
  workflow's package uploads go. In their place the spec's "Installing"
  section: the release tarball built in CI, `install.sh` with its one
  package-name table for pacman, apt and dnf, and the `formalshell
  install|update|uninstall` subcommands. Tested in three fresh containers
  (Arch, Debian, Fedora) from nothing to a running shell in a nested
  session; no other distros.

## Task 2: delete the QML shell

- `shell/`, `greeter/`'s QML, `tests/*.qml` and their stubs and fixtures
  that only QML read, the quickshell flake input, the `qml-tests` and
  `qmllint` checks, `*.frag` shaders, `FS_IMPL` (Rust is the only
  implementation; `dev/smoke.sh` loses its QML path), `dev/parity.sh` and
  `dev/ipc-golden.sh`'s recording against `qs` (the golden file stays as a
  fixed contract).
- Pure logic crates keep their ported tests; fixtures they read move under
  `crates/`.

## Task 3: docs

- CLAUDE.md rewritten for the Rust tree (verification loop, rig, hard
  rules: the pure QML/JS rule is gone; the ScreencopyView ban becomes the
  capture rule), README, docs/USAGE.md, docs/ARCHITECTURE.md, DESIGN.md
  references to QML components.

## Task 4: measure on e1504g (owner present)

- The R0 table again with the real shell, nested on e1504g in power
  saver: idle CPU, spinner CPU, panel and launcher frame times, the 33 ms
  bar gap during a launcher open, RSS after an hour, cold start. Against
  the spec's budgets.

### Results, e1504g, 2026-10-07

Both shells built on g815 at a2b48c67 against e1504g's own nixpkgs
(`55ba7f49`), copied over, run nested through `dev/smoke.sh` with
`FS_RESULT`/`FS_RS_RESULT`: `FS_IMPL=rust --menu-budget`, then
`--r0-measure 600` for each shell. Power profile `power-saver` for all
three runs (set with `sudo -n`: polkit refuses `powerprofilesctl set` over
ssh), `balanced` restored after. RSS is at 600 s, not an hour.

| | Budget | Rust | QML | Verdict |
|---|---|---|---|---|
| CPU, 60 s idle | 0.0% | 1.46% | void | fail |
| CPU, 60 s spinner | < 2% | void | void | not measured |
| Frames, ten panel opens | none over 16 ms | void | void | not measured |
| Launcher, toggle to first commit (worst of 5) | < 50 ms | 174 ms | void | fail |
| Bar gap across a launcher open (worst of 5) | < 33 ms | 184 ms | void | fail |
| RSS at 600 s | < 120 MB | 65 MB | 314 MB | pass |
| Cold start to first bar frame | < 300 ms | 1249 ms | 36.8 s | fail |

- Void rows: every run left its nested Hyprland alive, reparented to pid 1
  past the rig's `timeout -k 10` (launched through
  `/run/wrappers/bin/Hyprland`; SIGTERM hangs, SIGKILL works). The host's scrolling
  layout then put each new nested window off screen at x=1920, and the
  rust r0 run got 19 frame callbacks in ten minutes, none after 3.6 s: the
  spinner and panel rows drew nothing. Four leftovers were killed by hand.
- QML idle: the shell took 36 s to load its config from a cold cache, so
  its first frame landed 16 s into the idle window (21.7% self plus 9.2%
  children over it). QML spinner window read 6.3%, unanimated.
- Rust idle: 0.88 s of CPU in 60 s with two bar commits and no frame
  requested. Cause not found yet; R0's VM reading was 0.00%.
- Launcher: the host gave callbacks every 57 ms in power saver (17 ms in
  balanced). Open 1 spent 98 ms in launcher layout on the UI loop, and the
  shell held a bar frame 180 ms; opens 2 to 5 took 50, 108, 19 and 14 ms to
  the first commit with 59 to 94 ms of shell hold. The first drawn launcher
  frame (not the 1x1 configure commit) landed 162 to 333 ms after the
  toggle. In balanced, the same leg read 44 ms worst first commit and 18 to
  28 ms of shell hold.
- Cold start: 139 ms from launch to the shell's own zero, 1110 ms from
  there to the first bar commit.

Not done: the frame rows need a rerun with the nested window in view and
no leftover sessions, on a host not running another benchmark (a peer's
ffmpeg/nd-hello bench and a `nix-collect-garbage` started on e1504g during
the QML run).

# M60: the pantheon theme

**Date:** 2026-09-17
**Status:** planned; starts on `m60-pantheon` (worktree `../FormalShell-m60`)
once M59 is on main.
**Spec:** `docs/superpowers/specs/2026-09-17-pantheon-mode-declarative-themes.md`,
Part 2. M59's plan carries the table mechanism this builds on.

## Owner's ask (2026-09-17)

"A mode for the shell to be like pantheon, but made for my keyboard based
setup and tiling WMs." And, going to bed: "I want to wake up seeing the
pantheon style desktop." So the order below is by what is on screen first,
and the two habits that can wait (the switcher, the dark schedule) come
last and may land the next day without the rest waiting on them.

## Decisions

**P1 The table.** `shell/Theme/themes/pantheon.js`, every role transcribed
from the spec's material tables with the per-mode alphas as `{ light, dark }`
pairs. Light and dark differ in `highlight` (white, white 0.2) and in the
shadow levels; the layer lists are otherwise the same objects. Radii: 3 for
controls (`sm`), 6 for `md`, 9 for `xl`; the pantheon preset in `presets.js`
sets `radius: 6` so `Tokens.radiusTokens` lands on 2/4/6/10, and the table
pins the roles that elementary pins (`popover` 6, `card` and bubbles 9,
`tooltip` 3, `button` 3) by number rather than by step.

**P2 Habits.** `{ bar: "wingpanel", emerge: "popover", notification: "bubble",
launcher: "grid", switcher: true }`. Each of the first four is a second
QML file beside the existing one, chosen by a `Loader` on the habit;
the metamorphosis file is moved, not edited, into its own name
(`BarStrip.qml`, `NotificationRow.qml`, ...) in the same commit, so the
diff shows the split.

**P3 Wingpanel bar.** `Surfaces/Bar/BarWingpanel.qml`: no strip card, no
hairline, cells as wingpanel indicators (`0.25rem` margin, `0 0.5rem`
padding, radius 3, the open one filling `highlight` 0.6). The paint comes
from `ThemeEngine.barPaint`, one of `light`, `dark`, `translucentLight`,
`translucentDark`, `maximized`, computed off the wallpaper band under the
bar (mean luminance, standard deviation, acutance, wingpanel's thresholds
180, 45, 8 and the 1.645 sigma rule) plus Hyprland's fullscreen state, and
published in `debug dump` as `bar.paint` with the three numbers. The
sampling reads the wallpaper file `ThemeEngine` already holds, downscaled,
never the screen.

**P4 Popover emerge.** `Drawer` grows `emerge: "popover"`: `joined: false`,
a `card` box with a `menu`-shaped frame, Gala's 150ms menu map (fade plus
a `Theme.space.md` travel out of the cell), no shoulders, no gap
published. The Panel, the centre, the launcher, polkit, the OSD and a
plugin overlay all read the habit; nothing else in them changes.

**P5 Bubble notifications.** `Surfaces/Notifications/NotificationBubble.qml`:
332 wide, radius 9, `card` box, icon left with a 6px gap, bold title, body
at 33 characters, round close button on hover, the 400ms flip-in (opacity
plus an x rotation from 90 through -10 at 60% to 0), restack on
`emphasizedDecel` 200ms with a 150/n stagger. Timeouts and the pending tier
are the service's and do not move. `notifications.sound` (default false)
plays through `canberra-gtk-play` when on PATH, with the honest fallback
of silence.

**P6 Grid default.** `launcher: "grid"` makes `menu.appGrid` default true
under pantheon and nothing else; the grid exists (M58).

**P7 Window chrome.** `chrome.js` grows `$border`, `$shadow`, `$shadowRange`,
`$shadowPower`, `$shadowOffset`, `$shadowColor` from the table's `window`
role, published into `formalshell-chrome.conf`; metamorphosis publishes
`$shadow = false`. The dotfiles' Hyprland decoration block reads them
(M60 Task 7 edits `users/kyandesutter/mixins/hyprland.nix` in
`~/.config/nix`, where `fsRadius` is hardcoded today).

**P8 The switcher.** `Surfaces/Switcher/Switcher.qml` over a `switcher` IPC
target (`next`, `prev`, `commit`, `cancel`, `state`), Gala's numbers from
the spec, drawn from the compositor backend's window list, keyboard only.
The Hyprland bind (`Alt+Tab`) lands in the dotfiles with Task 7.

**P9 Dark schedule.** `theme.mode: "auto"`: sunrise and sunset from the
Weather module's coordinates through the NOAA formula (elementary's
`SunriseSunsetCalculator`), 20:00 to 06:00 without a location, checked
once a minute, flipping `ThemeEngine`'s mode the way `theme mode toggle`
does.

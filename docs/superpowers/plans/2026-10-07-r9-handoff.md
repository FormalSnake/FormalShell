## Rig rules learned the hard way

- Every VM run goes through `dev/vm-lock.sh` (two slots; `dev/vm.sh` now
  takes the lock itself if skipped). Smoke runs build the shell on the mac
  and copy it into the VM (`FS_BUILD_IN_VM=1` to build inside).
- Never run `dev/linux-builder.sh start|stop` from an agent; it is shared.
- Watch `df -h /` on the mac: under ~15 GB, `nix-store --gc` (rollback
  generations survive), never `nix-collect-garbage -d`. Never copy a VM
  image without checking free space for the copy first.
- Never build anything on e1504g; build on g815 against e1504g's nixpkgs.
- Agents: one task per agent in its own worktree (`isolation: worktree`),
  the owner's "uncommitted work is never yours to discard" section pasted
  verbatim into every prompt, a time budget, "wait on long commands rather
  than ending your turn". Merge their branches yourself in the main
  checkout; for semantic conflicts hand the merge to an opus resolver.
- Commits: conventional, lowercase, no body, no Co-Authored-By. Never touch
  git identity. Never push without the owner's go.
